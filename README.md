# Git training starter

This is a pracitce repository for the Git module. It contains made-up files only.
You can edit, break and delete anything in it. Nothing here is real work.

## What's in here

| Path | Used for |
|---|---|
| `docs/glossary.md` | Your first commits, and the merge-conflict exercise (line 3) |
| `docs/request-process.md` | A short process document to edit |
| `templates/` | A meeting-notes template and a weekly-update template, used in later modules |
| `exercises/module-4/` | The code review exercise |
| `.gitignore` | Tells Git which files to ignore (used in module 6) |

## Ground rules

1. Work only in your own copy of this repository.
2. Never put real passwords, keys or business data in any file here.
3. If you get stuck, run `git status` and read what it says before asking for help.

## Practice fixing a typo

The first sentence of this file has a deliberate spelling mistake. Find it and fix it on a
branch (module 3, part B). Your fix will be your first real change.
